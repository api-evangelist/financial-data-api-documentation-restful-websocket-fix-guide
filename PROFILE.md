## APIs

- **iTick Market Data API** — Token-authenticated REST and WebSocket API for real-time and historical financial market data across crypto, forex, indices, stock, future, and fund product lines. (`https://api.itick.org`)

> Self-serve REST API at https://api.itick.org/{product} and WebSocket at wss://api.itick.org/{product} (free trial at api-free.itick.org), all token-header authenticated. Hosted MCP server at https://api.itick.org/mcp (streamable_http, token header, exposes REST capabilities only) documented for Cursor, Claude Desktop, OpenCode, and langchain_mcp_adapters. llms.txt declared at https://docs.itick.org/llms.txt but contents not independently verified. iTick also publishes an Agent SDK (npm @itick/chat-core, @itick/chat-react, @itick/chat-vue) backed by an Agent Streaming Chat API at https://agent.itick.org/agent/stream/v1 — an embeddable conversational widget, not portable agent-skill manifests. FIX protocol is documented but institutional-only with no public base URL. No machine-readable API contract (OpenAPI/AsyncAPI/GraphQL/Postman) was found publicly. apis.json confirmed live at https://docs.itick.org/apis.json.
